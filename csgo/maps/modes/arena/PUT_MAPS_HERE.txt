Maps for: Multi-1v1 arenas
==========================

This mode only uses multi-1v1 arena (am_) maps from the Steam Workshop.
download_community_maps.bat downloads them straight from the Workshop
(start_server.bat runs it for you) into this folder:
    csgo\maps\modes\arena\

Standard maps (maplist.txt, Workshop ids in downloads.txt):
    am_must2, am_dust2, am_texture2, am_aztec2, am_grass2, am_warehouse2, am_water, am_trainyard, am_skybound, am_crashz_dust, am_inferno_banana_dolnma

When an admin picks "Multi-1v1 arenas" in !gamemode (or !1v1), the map menu shows
the maps in this folder, the installed maplist.txt maps, and any
am_ maps elsewhere on the server (incl. maps\workshop).

To add a Workshop map: put a line in downloads.txt
    <map name>  workshop:<Workshop id>
and its name in maplist.txt, then run download_community_maps.bat.
Use original CS:GO uploads - maps updated to CS2 (.vpk) can't load in CS:GO.
