Maps for: KZ (climb)
====================

Put .bsp map files for this game mode in this folder:
    csgo\maps\modes\kz\

When an admin picks "KZ (climb)" in !gamemode (or !1v1), the map menu shows:
  1. every .bsp in this folder
  2. the installed maps from maplist.txt
  3. other suitable maps on the server
  4. maplist.txt maps that aren't installed, greyed out

Standard maps for this mode (maplist.txt):
    kz_experiment, kz_exps_cursedjourney

These are community maps - CS:GO doesn't come with them, so they show
greyed out as (not installed) until you add them. Run download_community_maps.bat
(in your csgo folder) to fetch them, or download the CS:GO versions
(e.g. from GameBanana or varq.net) and drop the .bsp in this folder.
The Steam Workshop now mostly has CS2 versions, which don't work in CS:GO.

  - Copy the .bsp file (and its .nav file, if it has one) here.
  - The file name is the map name: surf_mesa.bsp shows as surf_mesa.
  - Add or remove names in maplist.txt to change the standard list.
  - No restart needed - just open the menu again.
  - If the map needs extra files (models, sounds, materials), put those in
    the normal csgo\models, csgo\sound and csgo\materials folders, or use a
    map whose .bsp has them packed in.

You can delete this text file.
